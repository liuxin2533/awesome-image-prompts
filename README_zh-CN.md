## 🗂️ 数据目录

`data/` 目录是本仓库的数据源头。人工和 AI 修正保存在 canonical 分片里；面向网站和下游工具的公开数据由这些分片导出。

<div align="center">

<table>
<tr>
<th align="center">路径</th>
<th align="center">用途</th>
</tr>
<tr>
<td align="center">`data/canonical/prompts/`</td>
<td align="center">按 prompt 拆分的 canonical JSON 数据，保留稳定 id、上游引用、翻译、资产、分类和本地修正。</td>
</tr>
<tr>
<td align="center">`data/catalog/`</td>
<td align="center">从 canonical 数据导出的多语言公开 JSON catalog，供网站和下游工具使用。</td>

<a id="快速开始"></a>

## ⚡ 快速开始

使用 pnpm 脚本完成可重复的采集、校验、导出、README 生成和本地审核。

<div align="center">

<table>
<tr>
<th align="center">命令</th>
<th align="center">作用</th>
</tr>
<tr>
<td align="center">`pnpm install`</td>
<td align="center">安装依赖。</td>
</tr>
<tr>
<td align="center">`pnpm ingest`</td>
<td align="center">解析已配置的上游仓库，合并数据，并保留已有本地修正。</td>
</tr>
<tr>
<td align="center">`pnpm validate`</td>
<td align="center">校验 canonical prompt 数据并刷新当前报告。</td>
</tr>
<tr>
<td align="center">`pnpm translate -- --language zh-CN`</td>
<td align="center">使用已配置的 AI 服务补齐缺失翻译。</td>
</tr>
<tr>
<td align="center">`pnpm classify`</td>
<td align="center">把上游分类映射到 canonical 分类，并暴露无法归类的问题。</td>
</tr>
<tr>
<td align="center">`pnpm assets:mirror`</td>
<td align="center">把缺失的远程资产镜像到本地资产缓存。</td>
</tr>
<tr>
<td align="center">`pnpm catalog:export -- --languages all`</td>
<td align="center">从 canonical 数据导出多语言 JSON catalog。</td>
</tr>
<tr>
<td align="center">`pnpm readme:generate -- --languages all`</td>
<td align="center">重新生成 README 和拆分后的分类文档。</td>
</tr>
<tr>
<td align="center">`pnpm workbench`</td>
<td align="center">启动本地维护工作台。</td>
</tr>
<tr>
<td align="center">`pnpm test`</td>
<td align="center">运行 ingestion、catalog、workbench 和 README 测试。</td>
</tr>
</table>

</div>

执行 `pnpm workbench` 后，打开 `http://127.0.0.1:4173`，可以处理警告、批量翻译、分类归类、导出 catalog，并重新生成 README。

<a id="如何贡献"></a>

## 🤝 如何贡献

欢迎提交贡献，但请确保 catalog 保持稳定、可追踪、可审核。

- Add or adjust upstream parsers under `scripts/ingestion/sources/`.
- Keep canonical ids stable and preserve existing human or AI translations.
- Run `pnpm test` before submitting generated catalog or README changes.
- Include source attribution for every imported prompt and preview asset.

<a id="协议"></a>

## 📄 协议

提示词正文、预览图片和上游元数据保留其原始上游归属和协议。本仓库脚本与生成的 catalog 结构用于目录整理和学习用途；复用数据时请保留来源署名。
